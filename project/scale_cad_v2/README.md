# 原始检测依赖

本目录只收录新版检测链使用的四个原组件，源码原样复制：

- `cad-complexity-screen`：原14个复杂特征扫描器、汇总规则与OCR。
- `parts_pdf`：同源内部图册、对齐及尺寸准备，包含原七指标分族算法。
- `step-exploded-view`：本检测链仅调用其STEP几何提取流程。
- `cad-dimension-sheets`：本检测链调用其解析STEP特征提取器。

检测主入口是相邻 `aichecker_new/run.sh`，不要用某个扫描器代替完整验收。主项目自动准备内部图册和缓存，不要求用户提交中间文件。

保留原文档用于追溯。其中提到的旧题包、人工复核样例、其他出图组件或 `example_harbor` 不属于本交接包，也不是新版检测链的必需输入。本包不宣称包含完整旧出图平台。
