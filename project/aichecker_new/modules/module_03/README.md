# 模块3

本模块所有维度都先执行原 STEP 前置检查；任意前置不通过或运行错误，后续均未执行。

输入只需一个多零件总装 `.stp/.step`，可直接指定文件，也可提交含该文件的目录（递归查找）。无需 PDF/DXF 或 SolidWorks。

- 维度1：仅检查 STEP/STP 文件是否提供；不渲染图纸、不做模型/图纸数量或内容配对、不调用 AI。
- 维度2：按原机械七指标去重后不少于100种零件；仍为本地代码检查，不累计重复安装数量。

前置、装配分类及两个维度同轮全部通过后，仍需完成最终查重入库才算完整验收通过。

从本目录运行：

```bash
bash run.sh --input-dir "/你的输入目录" --dimension all --llm off
```

仅测试第一维度（不入库），也可以直接给文件：

```bash
bash run.sh --step "/路径/总装.step" --dimension 1 --llm off
```

`--llm auto` 与 `off` 均不产生本模块 AI 请求，不需要密钥。注意：`--llm off` 不是禁止入库开关，完整模块通过后仍会登记；试跑完整模块请指定 `--dedup-registry "/你的测试库副本.json"`。

可单选 --dimension 1 / 2。去重采用 mechanical-seven-v2，不按重复安装数计数。
详细输入规则、环境配置和输出说明见 [项目说明](../../README.md)。
