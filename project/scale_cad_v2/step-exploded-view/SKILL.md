# STEP 工程爆炸图

使用真实 STEP 几何，输出高清 PNG、预览图、可编辑 Blender 场景和可复用展开配置。用宿主机 FreeCAD Python 提取实体，宿主机 Blender 渲染，Python/Pillow 排版。不需要 AI 生图，也不依赖 ALE 题包、GT 或特定零件编号。

## 工作流程

1. 先定位输入 STEP、输出目录和本 skill 的实际路径。读取 [运行与配置](references/workflow.md)，检查宿主机 FreeCAD Python、Blender、Pillow。输出放在本次任务独立目录，不放进 skill；不改源 STEP。
2. 执行 `pipeline.py extract`，得到 `catalog.json` 和压缩网格。用 `init-plan` 创建包含全部实体零位移的 `plan.json`，执行 `render --assembled` 并查看生成图片。结合零件中心、尺寸、体积和圆柱轴向理解装配。默认 ID 是本次导出的身份标识，不是原 STEP 名称或 BOM 编号。
3. 根据几何和用户用途，编辑 `plan.json` 的 `offsets`、`callouts` 和必要的 `guides`。方向、位移、标签锚点配置见 [运行与配置](references/workflow.md)。不要把“自动径向散开”当作已经正确理解了装配。壳体、板件、轴系等判断需要对图和清单做实际检查；不清楚的零件使用中性名称。
4. 执行 `render`。脚本自动取景、裁剪范围、工程灰色着色、轮廓和蓝色圈号排版。查看 `exploded_preview.png`，修正遮挡、箭头端点和层间距，然后重渲染。视图复杂时保留子装配并另做局部图，不强制把每个小件都编号。
5. 交付 `exploded.png`、`exploded.blend`、`plan.json`；按需附 `catalog.json`、压缩网格和装配预览以便重渲染。说明这是示意展开距离，除非另做过验证，不声称验证了实际拆卸路径、碰撞或装配顺序。

## 布局判断

- 先选稳定的主体/底座保留原位；箱盖、面板沿适合拆分的方向移出。轴承、垫片、端盖通常沿各自轴线展开。表达装配层次时，偏斜轴线不能强行替换为全局 X/Y/Z；为避免遮挡而做的构图侧移，应明确属于示意位置。
- 采用“子装配整体位移 + 组内附件轴向位移”设计，最后将两者相加写入每件的 offset。默认只平移，不缩放或旋转零件，保留几何和朝向。
- 爆炸总图以主要组件的轮廓分离为目标：底座、箱盖、各轴系之间应有可见空隙，不能仅把箱盖略微抬起。先按组件投影尺寸安排层间距，以最终图中相邻主要组件的净空约为较小组件投影尺寸的 10%–20% 作为起点，再根据遮挡调整；这只是构图参考，不是机械尺寸。
- 小附件先用满足可见性的最小间距，保持靠近安装位置。不要为了完整露出而沿轴线无限拉远；若与其它组件重叠，可按画面方向小幅侧移，保留原高度和朝向。用户说“稍微向左/右”时按相机视平面理解，可用 `scripts/nudge_plan.py`，其参数与使用方式见 [运行与配置](references/workflow.md)。
- 用户要求“再爆炸一点”时，优先增加主体与各子装配的分离距离，并适当增加端盖、轴承和紧固件的轴向间距；可以从原位移的 1.5–2 倍试起，但必须重新检查投影，不能只机械放大所有 offset。自动取景会缩小模型，应在最终 PDF 页尺寸下确认小件仍可辨认；必要时调整相机方向或画幅，保留清楚的装配对应关系。
- 用户参考图呈现逐件展开时，采用“轴系内逐层展开”而非只分开整个轴系：沿真实轴线依次分离齿轮/轴、轴承、隔套、垫片、端盖及端盖螺栓；箱盖、检修盖、密封垫和通气件也分别成层。根据原始几何位置确认层次，避免将轴承留在封闭端盖内或把垫片与盖面贴合。重复螺栓保持原孔位阵列，只统一沿轴向移出。
- 详细爆炸图的圈号可覆盖壳体、轴系和代表性附件，不必给全部实体编号；图例说明组件级编号含义。用沿轴线排列的小件建立对应关系，在最终页面检查每一层是否可辨，避免为追求空隙把整张图拉得过长。
- 齿轮、轴和键是否拆开取决于总图可读性；相邻轴系按投影结果调层间距，不能只看三维距离。重复紧固件保留组内相对关系，避免无意义逐件散开。
- 优先少量组件级圈号并附图例，明确与源零件编号的区别。默认箭头指向包围盒中心，可能落在孔洞或遮挡区；视觉检查后用 `anchor` 指定实体表面点，必要时改左右侧。
- PNG 采用 Workbench 阴影、轮廓与 cavity，接近工程插图，但不是 CAD 隐线消除的矢量图。若用户明确要真实矢量 SVG/PDF，应另用 FreeCAD/TechDraw 对展开后的 BRep 投影；不能将嵌入 PNG 的 SVG 描述为矢量线稿。

## 检查要点

- 导出、网格、配置、场景中的实体数量一致；计划覆盖每个 ID 一次；源文件及清单校验和一致。
- STEP 可能没有装配层级，或只剩一个融合实体。脚本不会凭空恢复原始零件；如需独立展开，说明实际限制并索取可用装配源或另行研究几何分割。
- 保留 world 坐标；OCC 的 BRep BoundBox 可能比网格实际边界宽，不要混用二者做极严的中心校验。重新导入或更换导入器可能改变实体顺序；旧计划不能只按数组下标套用。
- 使用宿主机 FreeCAD Python 读取输入。提取时暂存 0644 的 STEP 副本并在结束后清理；源文件权限不需为此改动。
- 实体数量一致不代表每件在图中可见。详细展开完成后，复查仍为零位移的独立附件，尤其是插在壳体内的细长杆、油尺状件、塞头和偏斜轴线零件；确认有意保留还是遗漏展开。需要展示时先尝试轴向抽出；若会离安装位置过远，采用较近的示意侧移，并在最终投影中检查完整轮廓；必要时单独标注，不能仅用实体总数作为可见性验收。
- 出图后实际查看 PNG，确认不空白、不裁切、主要零件可辨认，图例不溢出。脚本会检查全透明图，仍不能替代视觉检查。清理本次输出中的备份和缓存，不删除用户原有文件。
